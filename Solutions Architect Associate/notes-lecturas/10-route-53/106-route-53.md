## Qué es Amazon Route 53

- Servicio DNS altamente disponible, escalable, totalmente administrado y autoritativo.
- También funciona como registrador de dominios.
- Permite comprobar la salud de los recursos.
- La fuente explica el nombre por el puerto DNS tradicional: `53`.

## Registros

Cada registro incluye:

- nombre de dominio o subdominio;
- tipo de registro;
- valor;
- política de enrutamiento;
- TTL, que controla cuánto tiempo guardan el registro los resolvers DNS.

## Tipos principales

| Tipo | Función |
| --- | --- |
| A | Nombre de host hacia IPv4. |
| AAAA | Nombre de host hacia IPv6. |
| CNAME | Nombre de host hacia otro nombre de host. No se usa en el apex de la zona. |
| NS | Servidores de nombres de la zona alojada. |

- La fuente también enumera CAA, DS, MX, NAPTR, PTR, SOA, TXT, SPF y SRV.

## Zonas alojadas

- **Pública:** registros que enrutan tráfico en Internet.
- **Privada:** registros que enrutan tráfico dentro de una o más VPC.
- Una zona es el contenedor de los registros de un dominio y sus subdominios.

## Claves de repaso

- Route 53 puede registrar el dominio, alojar sus registros y aplicar controles de salud.
- Un registro define cómo responder una consulta; una zona agrupa registros.
- Autoritativo significa que Route 53 contiene la respuesta oficial para la zona administrada.
